# LipiLens — Teaching Computers to Read History

**In one line:** Take a photo of a centuries-old handwritten document, and
LipiLens reads it out for you in modern script — with a human expert always
checking its work.

## The problem, simply put

Hundreds of years ago, Maharashtra wrote in **Modi script** — beautiful,
flowing handwriting used for land records, letters, and court papers. Today,
almost nobody can read it, there is no Google-Translate-like tool for it, and
the old pages themselves are fading, stained, and torn. Knowledge locked on
those pages is slowly disappearing.

## What LipiLens does

1. **You upload a photo** of an old manuscript page.
2. **It cleans the photo** — removes noise, sharpens faded ink, straightens
   the page (you can compare before/after with a slider).
3. **AI reads it** and writes out the text in modern Devanagari script.
4. **A human verifies it.** The AI's draft is always clearly marked as a
   *draft* — it only becomes trusted after a person reviews and approves it.
5. **Everything is saved and searchable** in your own digital library.

## What we discovered (honestly)

We tested 7 cleaning styles on 20 real manuscript pages and measured every
result against expert readings:

![Results](docs/sweep_means.png)

- **The original photo usually reads best.** Fancy cleaning mostly doesn't help.
- **Black-and-white conversion clearly hurts** — it erases faint strokes the
  AI was actually using.
- **Doing "everything" is the worst option.** More processing ≠ better reading.
- Average accuracy: about **7 out of 10 characters correct** — a genuinely
  useful first draft for an expert, never a final answer.

We also show our failures openly: one page came back fluent but completely
wrong. That is exactly why the app never trusts the AI blindly. Full proof,
image by image, is in [`showcase/GROUND_TRUTH.md`](showcase/GROUND_TRUTH.md),
and the formal paper is at [`research/lipilens_paper.pdf`](research/lipilens_paper.pdf).

## Try it yourself

You need: a computer with Python and Node.js, plus a free Google Colab
account (that gives the AI its brain — free).

```bash
# 1. Get the project
git clone <your-repo-url>
cd lipilensv2

# 2. Set up the backend (the engine room)
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

```bash
# 3. Start the AI brain (in Google Colab, free GPU)
#    Open colab/lipilens_colab_server.py in Colab, run it,
#    and paste its web address into your .env file as COLAB_ENDPOINT_URL
```

```bash
# 4. Start the backend
python -m uvicorn backend.main:app --port 8000

# 5. Start the website (in a second terminal)
cd frontend
npm install
npm run dev
```

Now open **http://localhost:5173** in your browser, upload a manuscript
photo (or one from `showcase/images/`), and watch it read.
