# Showcase — 50 real Modi pages with proof of true transcription

Each row: the **original manuscript image**, the **expert Devanagari
reading** shipped with the dataset (ground truth — not ours), and **our
model's output** with its measured CER. Judges can verify by reading the
image against the expert text, then seeing how close the model came.

Source: `historyHulk/MoDeTrans` (IIT Roorkee, MIT license, paper arXiv
2503.13060). Model: Qwen2.5-VL-3B + `lgtk/qwen25vl-3b-modi-synth-lora`
via Colab GPU, official prompt, greedy decoding. CER = character error
rate vs the expert reading (0 = perfect).
